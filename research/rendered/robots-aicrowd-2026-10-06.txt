# NO REMOVED PATH MAY EVER BE Disallow-ED HERE.
#
# The Blitz / Notebooks / Reputation removal programme retires URLs by answering
# 410 Gone (design spec §5; the inventory is the routes.rb block above
# `root 'landing_page#index'`). Disallow blocks CRAWLING, not INDEXING — so a
# Disallow on a retired path means Googlebot never fetches it, never sees the 410,
# and the stale entry sits in the index indefinitely. This site has already paid
# for that lesson once: /participants was Disallowed on 2026-06-18 and ~100k
# SEO-spam profiles stayed indexed until it was re-allowed on 2026-08-18 (see the
# comment above).
#
# The 410s need to be crawled to work. Leave them crawlable.
#
# Note Crawl-delay above is ignored by Googlebot but honoured by Bingbot, so Bing
# drains the retired URLs more slowly. That is expected, not a fault.
