pocket-tts-onnx

Kyutai's Pocket TTS exported to ONNX for
pocket-tts-onnx , including a Hebrew IPA
adapter. Runs in the browser on onnxruntime-web, or in Python with onnxruntime and numpy.

Try it: https://thewh1teagle.github.io/pocket-tts-onnx/

Web asset set

The browser app fetches these; they are hosted here rather than in a GitHub release because
release assets are not served with CORS headers.
