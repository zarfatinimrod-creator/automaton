**הדירקטוריון פסק (ב)**, וזו גם ההמלצה שלי: זה מה שמקיים "שום קשר לשם שלי". אם אתה מעדיף (א) — תגיד.

## צעד 5 — לקנות דומיין

**זמן: 10 דקות. תשלום אחד מתוך ה-₪200 שאישרת.**

   **פסק הדירקטוריון: סיומת `.com`, לא `.co.il`** — כי ב-`.com` אפשר להסתיר את פרטי הבעלים (WHOIS privacy),
   וכללי הפרטיות של `.co.il` לא אומתו מכאן. כשקונים, סמן **WHOIS privacy / Domain privacy** (בדרך כלל חינם).

4. שמור את מספר הקבלה — אני רושם אותו בלדג'ר כהוצאה.

**חשוב:** דומיין הוא הוצאה **שנתית**. ה-₪200 מכסים את התשלום **הראשון** בלבד. החידוש בשנה הבאה הוא
החלטה שלך מחדש, לא משיכה אוטומטית — כך כתוב במנדט, ואני מקיים את זה.

### מה זה עושה
היום כל כתובת של האתר היא `משהו.netlify.app` — כתובת של ספק. דומיין נותן כתובת משלנו, שגם Google
מתייחס אליה ברצינות, וגם חנויות בודקות אותה כשמאשרים חשבון.

### מה יוצא לך מזה

## צעד 6 — לחבר את Netlify, להדביק שני טוקנים ב-GitHub, וקליק אחד ב-Apify

**זמן: 15 דקות.**

הקונטיינר שאני רץ בו **חסום** מלגשת ל-Netlify, ל-Apify ול-Gumroad. **GitHub Actions** (המכונות של
GitHub) כן מגיעות. אז אני כותב את הפקודות, והן רצות שם, עם הטוקנים שרק הן רואות.

### חלק א — Netlify (האתר)
1. פתח https://app.netlify.com. יש כבר אתר בשם `il-biz-tools` (מזהה `2087c2ed-5270-4407-8746-675d6ea41d5e`).
2. לחץ עליו → הגדרות בנייה ופריסה 🔍 → **Link repository** (חיבור ל-GitHub). בחר את הריפו `automaton`,
   ענף `main`. אם אין אתר: **Add new site → Import an existing project → GitHub → automaton** 🔍.
3. בהגדרות הבנייה, **בדיוק** (זה מה שקובץ ההגדרות בריפו מצהיר; הקודם שכתבתי היה שגוי):
   - Base directory: `products/il-biz-tools`
   - Build command: `node scripts/build-site.js`
   - Publish directory: `_site`
4. Deploy. מעכשיו כל שינוי שאני דוחף ל-`main` עולה לאתר לבד. אין צורך בטוקן של Netlify.
   (רק אם החיבור לא מצליח: טוקן אישי ב-Netlify 🔍 → GitHub Secret בשם `NETLIFY_AUTH_TOKEN`, ואז אני
   אכתוב את הפריסה דרך CLI. את `NETLIFY_SITE_ID` אני כבר יודע.)

## צעד 7 — להעביר את הריפו לארגון ב-GitHub

**זמן: 10 דקות.**

### מה לעשות
1. ב-GitHub, למעלה מימין, **"+" → New organization**, מסלול **Free**. שם הארגון: שם המותג (כמו בדומיין).
2. פתח https://github.com/zarfatinimrod-creator/automaton/settings
3. גלול עד למטה, **Danger Zone → Transfer ownership**. הקלד את שם הארגון כיעד, ו**את שם הריפו
   (`automaton`) לאישור** — זה מה ש-GitHub מבקש להקליד.
4. **חשוב, אחרת אני מאבד גישה:** ב-claude.ai → **Settings → Connectors → GitHub** 🔍, תן ל-Claude גישה
   גם לארגון החדש.
5. אחרי ההעברה, **בדוק שהסודות מצעד 6 עדיין מופיעים** בהגדרות הריפו (Settings → Secrets). אם לא —
   הדבק שוב. טוקן Gumroad שנעלם עוצר בשקט את הדבר היחיד שרושם כסף בלדג'ר.
6. תגיד לי את שם הארגון. את חיבור Netlify אולי צריך לחבר מחדש — אני אגיד לך.

### מה זה עושה
היום כל קובץ בריפו נגיש בכתובת `github.com/zarfatinimrod-creator/...` — **השם שלך בכל URL**, כולל
במקומות שיהיו ציבוריים (חנויות, רישומים, קישורים בתוך המוצרים). ארגון הוא בעלים בשם מותג.

### מה יוצא לך מזה
זה מה שמקיים את "שלא יהיה שום קשר לשם שלי בשום דבר" בצד הקוד. בלי הצעד הזה, אני **לא יכול לפרסם** שום
דבר מהריפו בלי שהשם שלך ייצא איתו. (מה שזה **לא** פותר: ההתחברות ל-Algora, ראה צעד 4.)
